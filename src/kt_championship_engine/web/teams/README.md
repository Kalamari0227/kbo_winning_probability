# KBO team emblems

These small PNG identity assets are served from the dashboard's local package so the page does not depend on a third-party image request at runtime. They were obtained from the image URLs used by the official [KBO club introduction page](https://www.koreabaseball.com/kbo/league/teaminfo.aspx), under `KBO_IMAGE/emblem/regular/fixed/emblem_{code}.png`.
